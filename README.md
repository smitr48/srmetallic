# S R Metallic — Showcase Website

A responsive one-page showcase website for S R Metallic, built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — website content
- `style.css` — design and responsive layout
- `script.js` — mobile navigation and footer year
- `images/` — supplied logo and product photos

## Publish free with GitHub Pages
1. Create a GitHub account.
2. Create a new public repository, e.g. `sr-metallic-website`.
3. Upload all files and the `images` folder.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select `main` and `/ (root)`, then Save.
7. GitHub will give you a public website address.

## Important

Replace it in `index.html` with the correct business phone number before publishing.
